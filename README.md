# 卜卜的圣诞小镇

2.5D 单机网页游戏的第一阶段场景原型。

## 运行

需要 Node.js 20.18+ 和 npm。

```sh
npm install
npm run dev
```

打开终端显示的本地网址。生产构建使用 `npm run build`，预览构建使用 `npm run preview`。构建产物位于 `dist/`，可以放到静态网站托管运行。

## 操作

使用鼠标点击道路或开放的铺装广场移动。道路按固定路线寻路，广场内可直接选择落点，并与道路连通。当前开放集市中央广场、车站中央空地和中央小镇下方圆形广场。点击建筑或圣诞树，会自动走到入口并打开弹窗。点击关闭或返回按钮回到小镇，问号按钮查看说明。

右上角“显示道路”开启测试标识。绿色区域显示道路与开放广场的实际可点击范围，细线表示固定路线，数字用于定位节点。切换区域时保留显示状态，再次点击“隐藏道路”关闭。可行走区域点击优先于与其重叠的建筑点击区域。

## 项目文件

### 不要欺负玛莎

难度在前60秒递增：抛出间隔由0.8秒缩短到0.26秒，飞行速度最高1.55倍，玛莎概率由28%升到40%，后期会成组抛出2–3个目标，同屏最多12个。60秒后难度封顶，暂停不推进，重试重置。玛莎头顶只显示“别点我”。

点击右上角“不要欺负玛莎”，或前往中央小镇的“礼物小屋”即可进入。点击小镇伙伴获得 1 分，点击玛莎扣除一次机会，3 次机会耗尽后结算。漏点不扣分。目标从底部抛起，沿抛物线自然落出画面，出现速度随游玩时间逐渐加快。支持暂停、继续、结算后重试和随时返回小镇；切到后台会自动暂停，最高分保存在当前浏览器。

本版复用小镇现有柠檬仔、青苹果、倔强卜、可爱柚和番茄君素材，并提供识别图例、按角色统计和点击反馈。玛莎使用用户提供的透明图片，界面采用小镇雪夜背景与暖灯木纹弹窗。参考 [game-space 的笑脸小游戏](https://github.com/chengzuopeng/game-space/tree/master/46-%E7%AC%91%E8%84%B8%E5%BE%AE%E7%AC%91%E5%B0%8F%E6%B8%B8%E6%88%8F) 的点击收集与误点扣机会机制，代码独立实现，未引入其运行时、图片和音频。本轮不接入星星奖励，退出不保留未结束的局。

`src/smile-game.ts` 提供独立 Phaser 游戏与弹窗生命周期。关闭弹窗销毁实例，地图角色保留原位。运行开发服务后可用 `node verify-smile.mjs` 检查玩法与接入流程，默认访问 `http://127.0.0.1:5175`，可通过 `SMILE_TEST_URL` 环境变量指定网址。脚本需要本地 Playwright 与 Edge。

- `src/town.ts` 负责共用的场景渲染、遮挡、角色和交互，`src/town-map.ts` 包含固定路线寻路，`src/areas.ts` 配置四个区域的路线、入口与遮挡。
- `src/main.ts` 创建游戏，`src/dialog.ts` 管理 HTML 弹窗。
- `src/style.css` 定义界面样式。
- `项目制作计划.md` 记录阶段、验收条件和后续任务。
- `references/` 保存官方角色参考。

中央小镇、圣诞集市、冰湖乐园和星光车站均已接入无角色底图、前景遮挡和独立角色图集。点击页面上方区域按钮切换，返回区域时保留本次页面会话中的停留位置与朝向。卜卜以四个 3/4 朝向沿固定道路蹦跳。前景层通过底图几何裁切进行深度遮挡，建筑和灯光尚未拆成独立透明贴图。各点位当前打开场景介绍。

运行开发服务后，打开 `/design/character-preview.html` 查看四方向动态预览。`design/bubu-three-quarter.gif` 为循环 GIF，`public/assets/characters/bubu-turnaround-v1.png` 为四方向透明素材图集。
