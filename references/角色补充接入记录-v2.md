使用内置 imagegen 逐个生成独立透明 PNG，输入用户提供的正面参考和既有小镇场景作为身份与风格参考。背面图片用于辅助核对，本批交付为单个 3/4 正面站姿，并非四方向动画。生成后只裁切透明边距，保留原始 alpha；移除挂件金属链和商品标签。素材在 `public/assets/characters/*-v1.png`，高度 73–96 世界像素，沿用现有呼吸、脚底阴影、按落点排序遮挡、悬停与透明像素点击。

随机分配：页面载入时打乱 8 个经过场景核对的街道候选位，5 个访客各占一位。固定角色位置不变；场景往返保持分配；重新打开或刷新页面重新抽取。不要求每个场景每次均有访客。不包含巡逻移动或小游戏；介绍对白为本项目创意文案。

验证：`npm run build`；`node verify-residents-v2.mjs` 使用 Edge 无头浏览器，检查四场景共 14 组 NPC，每个角色恰好出现一次，逐个点击打开对应介绍，场景往返保持分配，无加载和运行错误。截图 `design/residents-{Town,Market,Lake,Station}-v2.png` 为当次随机结果。
